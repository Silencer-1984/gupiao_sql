## 0. 阅读说明

### 0.1 本字典的口径

1. 表中所有「接口」「参数」「返回字段」「最早日期」均为**实际调用后**记录，不是文档推测。
2. 验证状态定义：

| 状态 | 含义 |
|---|---|
| `verified` | 全部参数组调用成功，字段与数据可用 |
| `partial` | 部分参数组失败（如个别股票/指数取不到） |
| `failed` | 全部失败（含被限流、上游接口结构变更） |
| `不支持` | 该数据在 AkShare 免费生态中不存在对应接口（不编造） |

3. 所有金额/量纲**保持源口径**，未做自动换算。「单位」一栏是必须遵守的换算依据。
4. `最早日期` 指接口真实返回的第一条数据的日期，不是指数基日，也不是理论可得日期。
5. 每种数据集的完整字段非空率、行数、样例见 `docs/data_catalog.md`（自动生成）。

### 0.1b 两套分类的对应关系

任务要求按「行情 / 成长 / 价值 / 周期 / 宏观 / 资金」组织，本字典的第 1~6 章即按此划分。
但同一份数据在落库侧按「数据形态」归类，因为**基本面与估值数据是三种风格共用的**（例如
`fin_yjbb` 既服务成长也服务价值与周期），若强行按风格拆表会重复存储 3 份。对应关系：

| 研究侧（本字典章节） | 落库侧 `config/data_sources.yaml` 的 `category` |
|---|---|
| 1 行情 | `行情`（9 个数据集） |
| 2 成长基本面 / 3 价值基本面 | `基本面`（8 个）+ `估值`（6 个），三风格共用 |
| 4 周期基本面 | `周期`（3 个）+ 复用 `宏观` 中的 PPI / 工业利润 |
| 5 宏观 | `宏观`（10 个） |
| 6 资金与情绪 | `资金`（5 个） |

### 0.2 三条贯穿全项目的口径陷阱（务必先读）

| # | 陷阱 | 具体表现 | 处理要求 |
|---|---|---|---|
| 1 | **中证 vs 国证涨跌幅单位不同** | 中证 `涨跌幅` 为百分数（3.87 = +3.87%）；国证 `涨跌幅` 为小数（0.0512 = +5.12%） | 入库后统一，禁止混算 |
| 2 | **两融三个接口三种单位** | `stock_margin_sse` = 元；`stock_margin_szse` = 亿元；`stock_margin_szse_js` = 元 | 只用 `_sse` + `_szse_js`（同为元）；`stock_margin_szse` 不用 |
| 3 | **统计月份 ≠ 可得日期** | 宏观接口只给「2026年10月份」，不给发布日；财报接口 `日期` 是报告期 | 回测必须用 `announce_date` / 发布日历滞后，否则未来函数 |

### 1.6 指数成分股

**（a）中证官方（主源）** `ak.index_stock_cons_weight_csindex` → `px_index_cons_csi`，5,767 行，**verified**（7/7）

字段：`as_of_date`(快照日期) / `index_code` / `index_name` / `stock_code` / `stock_name` / `exchange` / `weight`(权重%)。
实测数量正确：沪深300=300、中证红利=100、红利低波=50、红利低波100=100、中证有色=50、科创50=50、中证全指=5,117。

**（b）新浪（补充）** `ak.index_stock_cons` → `px_index_cons`，去重后 2,569 行，**有缺陷**
实测重复行严重：沪深300 返回 300 行但仅 **289** 个不同代码；中证全指返回 5,117 行但仅 **1,930** 个不同代码 → 成分股不完整，不可作主源。

> **重大限制（两条）**
> 1. 两者都只是**当前快照**，无法还原 2015—2025 年各期历史成分股。用今天成分股回溯 2015 年 = 存活偏差 + 前视偏差。
> 2. 解决办法（下一阶段）：每月定时留档一次快照，或用中证官网定期调整公告重建；本阶段数据不足以做严格历史成分股回测。

| 沪市成交额 | `stock_summary_sse` | **只返回最近一个交易日，无历史** → 不可用 |

### 6.5 拥挤度与广度（重要区分）

| 概念 | 定义 | 本项目指标 | 数据来源 | 可得性 |
|---|---|---|---|---|
| **风格拥挤度** | 资金与交易过度集中于某风格 | 该风格指数成交额占全 A 比例的历史分位；换手率历史分位 | `px_index_daily_csi.amount` ÷ 000985 amount；`px_index_daily_tx.turnover` | ✅ 可算（2015 起日频） |
| **风格广度** | 上涨/估值改善是否扩散到多数成分股 | 成分股中收盘价高于 MA20 的比例；成分股 PE 下降比例 | 需要**全部成分股日行情** | ⚠️ 当前只有指数级数据，个股日行情未采集 → **本阶段不可算** |
| 全市场拥挤度 | 全市场换手/成交集中度 | `stock_a_congestion_lg`（乐咕） | `val_congestion_lg`，3,687 行，2011-09 起 | ⚠️ 尾部 50 个交易日为空 |

> 结论：**广度与拥挤度不能用同一指标替代**。目前拥挤度可算，广度因缺少成分股面板数据而不可算，需在下一阶段补个股日行情（`stock_zh_a_hist` 逐股，或指数成分股权重×个股行情）。
