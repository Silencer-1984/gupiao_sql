# 数据源调研报告

> 调研时间：2026-11-22　AkShare 1.20.65　Python 3.13.12　Windows 11
> 全部结论基于**真实接口调用**（共 254 次调用，245 次成功，成功率 96.5%），非文档推测。
> 明细：`data/verification_report.json`、SQLite `meta_fetch` 表、`data/run_full_1.log`

---

## 1. 一句话结论

| 类别 | 结论 |
|---|---|
| 指数行情 | **完全够用**，且质量优于东方财富——中证官网自带指数 PE-TTM 日频序列 |
| 成长基本面 | **基本够用**：营收/利润/ROE/毛利率/现金流/PE/PS/PB 均有源；**研发费用率、分析师预测修正不可得** |
| 价值基本面 | **有硬缺口**：红利指数**历史股息率无法免费获取**（只有最近 20 个交易日） |
| 周期基本面 | **半够用**：铜铝金价格与 PPI/工业利润可用；**库存只有近 60 日、供需表不可得** |
| 宏观 | **够用**：10 项全部可采；但**发布日全部缺失**，必须自己按发布节奏滞后 |
| 资金情绪 | **部分够用**：两融/成交额/换手率可用；**北向 2024-08 断供、ETF 净流入不可得** |
| 历史成分股 | **不可得**（只有当前快照）→ 回测存在存活偏差风险 |
| 风格广度 | **当前不可算**（缺个股日行情面板） |

## 3. 需要其他数据源 / 需自建的数据

| 数据 | AkShare 状况 | 替代方案 | 成本 |
|---|---|---|---|
| 红利指数历史股息率 | 仅 20 个交易日（`index_value_csindex`） | ① 自建：成分股分红明细 ÷ 总市值，算 TTM 股息率<br>② 中证官网月度估值文件逐月抓取 | 中（100 只成分股 × 分红明细） |
| 指数 PB（红利/有色/成长） | 乐咕只覆盖 4 个宽基 | 自建：成分股 PB 加权，或用 `index_value_csindex` 的 PE + 成分股 PB 估算 | 高 |
| 指数 PS-TTM | 无指数级接口 | 个股 `stock_value_em.ps_ttm` 加权聚合 | 高（需全市场逐股） |
| 研发费用率 | yjbb 不含 | `stock_profit_sheet_by_report_em` 逐股取利润表「研发费用」÷ 营业收入 | 高（全市场 5,000+ 次） |
| 工业金属库存长历史 | 只有近 60 交易日 | 上期所/大商所周报；或付费源 | 中 |
| 有色金属供需平衡表 | 无接口 | SMM、Wind、Choice（付费） | 付费 |
| 历史成分股（逐期） | 只有当前快照 | ① 每月定时留档快照<br>② 抓中证官网定期调整公告重建 | 中 |
| 全 A 换手率长序列 | 沪市总貌仅当日 | 自算：全 A 成交额 ÷ 自由流通市值（需个股流通市值面板） | 高 |
| 风格广度 | 无 | 个股日行情面板 + 成分股名单 | 高（全市场逐股） |
| 指数基日/基期 | `index_stock_info` 只给发布日 | 中证/国证官网手工补 9 个指数即可 | 低 |
| 社融最新月份 | 该源滞后至 2026-04 | 央行官网 / 国家统计局 | 低 |

## 4. 无法免费获取（明确缺失，不伪造）

1. **分析师盈利预测的历史修正**（上调/下调、一致预期变动）：只有当前快照（`stock_profit_forecast_em`，141 行）。
2. **ETF 日频真实资金净流入**：免费源无申赎数据，只能用份额变化 × 净值近似。
3. **有色金属供需平衡表**（产量、消费、库存消费比）。
4. **红利指数历史股息率官方序列**（20 日窗口外）。
5. **DR007 2015-2016**：FDR007 自 2017-05-31 才有。
6. **全市场逐日换手率**（沪市总貌接口只返回最近交易日）。

## 5. 存在稳定性问题的接口（实测）

| 接口 | 问题 | 现象 | 应对 |
|---|---|---|---|
| `index_zh_hist_em` / `index_zh_daily_em` / `fund_etf_hist_em` | **东方财富 push2 行情服务器 IP 限流** | `Push2RateLimitError`，提示首次约 5 分钟、反复触发 40 分钟以上 | 行情改用中证/国证/新浪/腾讯；东财仅作备用 |
| `index_analysis_daily_sw`（申万行业日报表） | **上游结构变更** | `KeyError: '发布日期'`，一级行业/风格指数均失败（含 PE/PB/股息率/成交额占比） | 本阶段不用；改用中证行情 + 财报聚合 |
| `stock_dividend_cninfo`（巨潮分红） | 部分股票返回结构异常 | 招商银行/紫金矿业/宝钢 `KeyError: 'records'`；中国神华/长江电力正常 | 用 `stock_history_dividend_detail`（新浪）兜底 |
| `stock_index_pe_lg` / `stock_index_pb_lg` | legulegu 站点 429 限流 + 参数不支持 | `创业板指` 抛 `KeyError`；`中证500/上证180` 曾 429 | 只保留 4 个宽基；失败后间隔重试 |
| `stock_summary_sse` | 设计限制 | 无参数，只返回最近一个交易日 | 沪市总貌无法做历史 |
| `fund_etf_scale_szse` | 签名与 SSE 不一致 | 不接受 `date` 参数 | 暂不使用 |
| `stock_margin_sse` | 单次返回行数上限 | 一次最多约 2,000 行（8 年） | 按年循环 |
| `interest_rate_repo_hist_cm` | 单次区间 ≤ 1 年 | 超过报错 | 按年循环 |
| `index_stock_cons_csindex` | 偶发超时 | 首次 `ReadTimeout`（oss-ch.csindex.com.cn） | 重试即可（第 2 次成功） |
| `stock_a_congestion_lg` | 数据尾部缺失 | 最近 50 个交易日 `congestion` 为空 | 仅作参考 |

## 8. 数据源优先级落地（对应任务第四节要求）

| 优先级 | 来源 | 本项目实际使用情况 |
|---|---|---|
