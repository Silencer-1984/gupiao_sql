## 二、本轮任务的定位（最重要，先读三遍）

上一轮解决了「数据有没有」。本轮只解决两件事：

1. **数据能不能用** —— 在严格 PIT（point-in-time）口径下，把原始表变成可回测的因子表。
2. **因子有没有信息** —— 单因子对未来 20/60/120 日**相对收益**的预测能力。

本轮**不做**：多因子权重优化、机器学习、自动交易、实盘信号。

### 2.1 路线降级（上一轮审查结论，必须遵守）

原计划「全 A 个股动态成长/价值打分池」在当前数据条件下**不可实现**（缺历史成分股 + 缺全市场个股日行情 + 缺分析师修正）。
本轮统一采用**指数/ETF 级轮动**：

- 成长：`000688` 科创50、`399006` 创业板指、`399296` 创成长
- 价值：`000922` 中证红利、`H30269` 红利低波、`930955` 红利低波100
- 周期：`000819` 中证有色金属
- 基准/分母：`000300` 沪深300、`000985` 中证全指

**因子一律在指数层面构造，不构造个股层面因子。** 个股财务数据只用于「指数加权聚合」这一种用途。

### 2.2 ETF 可用性的硬约束（必须写进回测）

成长/价值双资产回测最早起点 = 2015-01；加入有色 = 2017-09；加入科创50 = 2019-12-31。

## 五、任务 3：红利指数历史股息率自建（唯一允许的新增采集）

这是价值侧唯一的核心信号，必须做，但范围要收窄。

实现步骤：

1. 取 `px_index_cons_csi` 中 `000922` / `H30269` / `930955` 的成分股（共约 250 个代码，去重后更少）。
2. 对每只成分股，用 `stock_history_dividend_detail`（新浪，已验证 5/5）取历年 `cash_div_per10` + `ex_date`；巨潮 `stock_dividend_cninfo` 仅作补充，失败即跳过并记录。
3. 用 `stock_value_em`（或等价接口）取每只成分股的 `total_mv`（总市值）；若只能取得流通市值，必须换口径并在报告标注，**不得混用**。
4. 按指数加权计算 TTM 股息率：
   `DY_index(t) = Σ_i (w_i(t) × DPS_ttm_i(t) / price_i(t))`，权重用当期成分股权重，缺失权重的成分股按剩余权重等比放大。
5. 与中证 `index_value_csindex` 最近 20 日的官方值做**交叉校验**：报出相关系数与平均绝对偏差。偏差 > 0.3 个百分点时必须分析原因（成分股缺失、分红口径、市值口径）并写入报告。
6. **明确承认的缺陷**：只有当前成分股名单，历史股息率存在存活偏差；必须在报告「风险」章节写明，且该因子的回测结论要标注「受存活偏差影响」。

若上述任一步骤在 2 小时内无法跑通，**停止并向用户报告卡点**，不要用「全 A 股息率」替代红利指数股息率（口径不同，会直接导致信号失效）。

## 六、任务 4：单因子有效性检验（本轮核心产出）

对每个因子 `x` 与每个标签 `y`，输出统一的结果表 `factor_test_results`：

| 列 | 说明 |
|---|---|
| `factor` / `target` / `sample` | 因子名、标签名、样本区间 |
| `n_obs` | 有效观测数 |
| `ic_spearman` | Spearman 秩相关（因子值 vs 未来收益） |
| `ic_mean` / `ic_std` / `ic_ir` | 滚动 60 日 IC 的均值、标准差、IR |
| `ic_positive_rate` | IC > 0 的占比 |
| `quantile_returns` | 5 分位组合的未来平均收益（JSON） |
| `monotonicity` | 分位收益的单调性（Spearman of quantile vs return） |
| `t_stat_newey_west` | Newey-West（lag=5）调整后的 t 值 |
| `start` / `end` / `note` | 区间与备注 |

硬性要求：

1. **禁止用全样本计算因子分位**，必须是滚动窗口。
2. **禁止在标签窗口重叠时忽略自相关**，t 值必须做 Newey-West。
3. IC 计算必须**按日期做横截面**，不要把所有日期混在一起算一次相关。
4. 每个因子至少报告：成长 vs 红利、成长 vs 有色、红利 vs 有色 三组相对收益的 IC。
5. 因子间相关性矩阵单独输出，相关 > 0.9 的因子对必须点名。

## 七、任务 5：最小回测（验证可行性，不追求收益）

策略定义（**固定，不要调参**）：

- 资产：科创50 / 中证红利 / 中证有色（缺数据期自动降为双资产）
- 信号：`z(gap_pe) + z(dy_minus_cn10y)` 的合成分数，**权重先等权**
- 调仓：月度（每月最后一个交易日）+ 5 日平滑两版
- 仓位：分数占优 70/30，接近均衡 50/50（不做 100/0）
- 成本：单边 0.05%，滑点 0.02%
- 基准：50% 科创50 + 50% 中证红利 恒定权重

输出：年化收益、年化波动、最大回撤、夏普、换手率、月度胜率、分年度收益，以及**相对恒定权重基准的超额**。

必须同时输出：

1. **无未来函数自检**：随机打乱未来收益标签后重跑，超额应接近 0。
2. **样本外切分**：2015–2021 训练（仅用于确定因子方向与分位阈值），2022–2026 检验。
3. **敏感性**：调仓频率（月/周/5日平滑）× 阈值（80/20、70/30）至少 6 组，报告收益分布而非只报最优组。

**禁止在任何文档里把这套回测的收益写成「预期收益」。**
