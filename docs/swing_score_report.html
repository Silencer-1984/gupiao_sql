五、怎么解读这张打分表

  • 模型能抓住 B / C / D 三次"价值买点"：起点 95 / 87 / 92 分，ERP 6.72 / 7.40 / 7.12，5y 分位 0~6%，四项全达标。这三次也是最干净的低位。
  • A（2022-05）是"急跌反弹"，不是价值买点：75 分全靠 MA60 -9%、回撤 -16%、连跌 2 天撑起来，ERP 只有 5.59。严格闸门拒绝，但事后涨了 14.27%——这是模型必然错过的类型。
  • E（2025-01）59 分是唯一"观望档"起点：ERP 6.45 差 0.05 没过线、5y 分位已 42%。事后涨 27.5% 且持续 242 交易日，是 6 段里第二强——但按价值框架它不该满仓买。
  • F（2026-04）27 分，模型明确拒绝：5y 分位 71%、ERP 5.42，只是 MA60 深跌的技术性反弹。事后仍涨 11.28%。
  • 终点全部低分，但卖出信号滞后：A/C/D 终点分位 41%/41%/63%，还没到 80% 卖出线；只有 E、F 终点分位 82%/94% 触发。打分模型比严格闸门更早提示"该走"，但仍跟不上价格顶。
  • 核心矛盾再次出现：打分最高的三次（B/C/D）事后涨幅 18.1%/15.1%/29.9%，而模型拒绝的 A/E/F 也涨了 14.3%/27.5%/11.3%。这套模型筛的是"赔率最好的买点"，不是"所有会涨的点"——想抓住后者需要另一套趋势/政策框架。
