## 3. 北向资金是不是"聪明钱"（用数据回答）

把 2,264 天的净买入与沪深 300 做对照：

| 关系                       | 相关系数      |
| ------------------------ | --------- |
| 北向(当日) vs 沪深300 **当日**收益 | **0.398** |
| 北向(当日) vs 沪深300 **次日**收益 | 0.070     |
| 北向(当日) vs 未来 **5 日**收益   | 0.041     |
| 北向(当日) vs 未来 **20 日**收益  | 0.050     |

按净买入五分组，看沪深 300 后续收益：

| 分组（净买入从低到高） |     次日 |    5 日 |   20 日 |
| ----------- | -----: | -----: | -----: |
| Q1（流出最多）    | -0.10% | -0.20% | -0.80% |
| Q2          | -0.10% | -0.14% | -0.44% |
| Q3          | -0.00% | +0.13% | +0.95% |
| Q4          | +0.11% | +0.29% | +0.63% |
| Q5（流入最多）    | +0.15% | +0.10% | +0.24% |

**结论：北向是同步指标，不是领先指标。**

- 与当日涨跌相关 0.398 —— 它跟着大盘走（追涨杀跌），不是它带着大盘走
- 与未来收益相关 0.04~0.07 —— 统计上接近噪声
- 五分组有微弱单调性（Q1 最差、Q5 次好），但 20 日收益最高的是 **Q3** 而不是 Q5，说明"买得越多涨得越好"不成立

「跟着北向抄作业」这个策略，在数据上站不住。它有用的是**当情绪温度计**（极端流出日往往对应市场恐慌底部），不是当买入信号。

## 4. 断供之后怎么办

| 替代方案        | 可行性        | 说明                     |
| ----------- | ---------- | ---------------------- |
| 南向资金（港股通）   | ✅ 每日可得，已入库 | 反映内资对港股的态度，可作离岸风险偏好代理  |
| 沪深港通成交总额    | ⚠️ 只有总量无方向 | 无法算出净买/净卖              |
| 外资持股季度数据    | ⚠️ 频率太低    | 无法做日频因子                |
| A50 期货基差/持仓 | 🟡 需另找数据源  | 可作外资情绪的间接代理，但噪声大       |
| 两融 + ETF 份额 | ✅ 已有       | 用境内杠杆与被动资金替代"资金面"这一类因子 |

**我的建议**：北向这条线，2014-08 之前的数据留着做历史回测（但要标注"该因子 2024-08 后失效"），当下不要指望它。资金面因子改用「两融同比 + 指数成交额占比 + 南向」。
