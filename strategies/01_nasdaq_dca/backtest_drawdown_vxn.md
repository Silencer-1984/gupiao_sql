# 回撤阶梯加码 & 均线偏离+VXN 共振：随机窗口回测

> 脚本 `scripts/backtest_drawdown_vxn.py`　seed=20261124　N=2000 组

## 1. 数据与口径

- 标的 `.NDX` 2014-02~2026-11；VXN 来自 Cboe 官方 CSV（`mkt_vol_vxn`，2009-09 起，与 .NDX 100% 对齐）
- 每月 15 号（顺延）投 5000，钱先入现金池；池子 >15000 强制投出；未投的钱不计时（保守口径）
- 随机起点 + 5~9 年窗口（60/72/84/96/108 月）
- 回撤 = 收盘 / 250日峰值 − 1；均线偏离 = 收盘 / MA200 − 1；VXN 分位 = 滚动 5 年

## 2. 策略定义

| 策略 | 规则 |
|---|---|
| D1 温和阶梯 | 回撤 >-5%投0；-5~-10%投1倍；-10~-20%投2倍；-20~-30%投3倍；<-30%投4倍 |
| D2 激进阶梯 | 同 D1，深档提到 4/6 倍 |
| D3 只加不减 | 浅回撤也投1倍；-10~-20%投1.5；-20~-30%投2；更深 3/4 倍 |
| S1 严格共振 | 偏离≤-10% 且 VXN分位≥70 → 3倍；否则偏离≤-20%投2、≤-10%投1.5、>10%投0.5 |
| S2 宽松共振 | 偏离≤-10% 或 (VXN分位≥80 且偏离<0) → 2倍；偏离>10% 投0.5 |
| S3 纯VXN分位 | ≥90投3、≥70投2、≤20投0.5（对照，不看均线）|

## 5. 结论

- 全样本总收益均值：无脑定投 93.00% / D1温和阶梯 88.98% / D2激进阶梯 89.46% / D3只加不减 93.00% / S1严格共振 89.61% / S2宽松共振 90.24% / S3纯VXN分位 90.76%
- 相对无脑的胜率：D1温和阶梯 0.0% / D2激进阶梯 0.0% / D3只加不减 0.0% / S1严格共振 1.1% / S2宽松共振 0.0% / S3纯VXN分位 0.0%
- 阶梯加码的资金来自「原本要投的钱」后移，不是外部增量；深跌时加码的收益来自低位多买，
  代价是上涨时空仓（暂停月）。看结果时务必同时看部署率、真实加码月与暂停月占比。
- 真实加码月占比：无脑定投 0.0% / D1温和阶梯 9.4% / D2激进阶梯 8.4% / D3只加不减 0.0% / S1严格共振 3.0% / S2宽松共振 7.0% / S3纯VXN分位 4.5%
  D3「只加不减」没有暂停月、也几乎没有真实加码月 → 等于无脑定投，这个结果符合预期：
  没有暂停就没有多余弹药，加码幅度被现金池上限（3 期）锁死。
- VXN 共振类策略在恐慌高位加码，若 VXN 高位常对应长期底部则有效；否则只增加空仓时间。
