# 月内逢低加码：每月1号定投 + 低于本月基准价就补仓

> 脚本 `scripts/backtest_intramonth_dip.py`　seed=20261124　N=2000 组，标的 .NDX

## 1. 规则

- 每月首个交易日（即「1号」顺延）投 **5000**，记该日收盘价为 P0
- 本月内之后每个交易日：若收盘价 **< P0**，按规则补仓；否则不动
- P0 每月重置；补仓金额不固定，按偏离度（P0/当日价−1）和当日跌幅决定

| 轨 | 补仓规则 |
|---|---|
| R0 基准 | 不补仓 |
| R1 固定100 | 低于P0就补100 |
| R2 固定200 | 低于P0就补200 |
| R3 偏离分档 | 偏离≥1%补100、≥2%补200、≥3%补300 |
| R4 跌幅分档 | 当日跌≥1%补100、≥2%补200、≥3%补300（且需低于P0）|
| R5 组合分档 | 偏离pp+当日跌幅pp：≥1补100、≥2补200、≥3补300 |

**双口径**：全成本收益＝期末市值/(5000×月数+补仓)；常规口径＝期末市值/(5000×月数)（补仓视作本来会花掉的钱）。

## 4. 结论

- R1固定100：全成本收益 93.00%（较基准 +0.66pp），常规口径 121.29%，总花费 480,321 元（较基准 +61,581）
- R2固定200：全成本收益 93.51%（较基准 +1.17pp），常规口径 150.23%，总花费 541,901 元（较基准 +123,161）
- R3偏离分档：全成本收益 92.34%（较基准 -0.01pp），常规口径 141.81%，总花费 527,092 元（较基准 +108,352）
- R4跌幅分档：全成本收益 92.40%（较基准 +0.06pp），常规口径 107.97%，总花费 452,857 元（较基准 +34,117）
- R5组合分档：全成本收益 92.51%（较基准 +0.17pp），常规口径 149.24%，总花费 542,810 元（较基准 +124,070）
- 补仓越猛，总花费越高；全成本收益是否提升取决于补仓价是否真低于平均成本。
- 常规口径天然偏高（补仓钱不进分母），只用于对照「备用金」场景。
