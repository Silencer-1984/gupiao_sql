# 按溢价分档加码的定投：为什么没用

> 2026-11-23　脚本 `scripts/backtest_tier_dca.py`　数据 `data/tier_dca_windows.csv`

## 1. 你提的策略（我照做了 5 个版本）

每月固定 5000 充入现金池，按当日溢价决定本月买多少：

| 版本 | 溢价 ≤3% | 3~8% | 8~15% | >15% |
|---|---|---|---|---|
| V1 | 4 倍（≤1%） | 2 倍 | 1 倍 | 0.5 倍 / 0 倍 |
| V2 | 3 倍（≤2%） | 2 倍 | 1 倍 | 0.5 / 0 |
| V3 | 2 倍（≤3%） | 1 倍 | 0.5 | 0 |
| V5 对称 | 2 倍（≤2%） | 1 倍（≤5%） | 0.5（≤10%） | 0 |
| P1/P2 分位档 | 按「近 250 日溢价分位」分档，30/70/90 或 20/60/85 | | | |

共同约束：现金池超过 3 期（15,000）的部分无条件立刻投出，防止资金长期停摆。

## 3. 为什么加码失效（这是重点）

### 原因一：加码的钱从哪来？

你只有 5000/月的现金流。要"低溢价加倍买"，钱只能来自**之前高溢价时少投攒下的**。

于是形成一个循环：

```
高溢价月 → 少投/不投（攒钱）
   ↓
低溢价月 → 把攒的钱一次投掉（加码）
```

听起来很合理，但问题是：**高溢价月往往不是"贵得离谱"的月份，低溢价月往往也不是"便宜"的月份。**

数据：溢价分位与未来指数收益的相关只有 **−0.06 ~ −0.15**（几乎无关）。
「低溢价」不等于「低点」，你只是换了个时间买，没有买到更好的价格。

### 原因二：攒钱有时间成本，加码的收益补不回来

- 闲置资金平均 917 元（V2）到 8,500 元（P2）
- 闲置期间零收益，市场涨就踏空
- 而"低溢价买入"的优势（60 日 +7.38% vs 高溢价 +2.64%）需要**额外资金**才能吃到，不是靠"挪时间"

结果：错过上涨的成本 ≈ 买到低价的收益 → 净效应为零（V2），甚至为负（分位档，闲置 12~14% 资金）。

### 原因三：分位档更糟，因为它把"暂停"条件设在"分位 >90"

2026 年溢价长期处在历史高位，分位档几乎全年触发 0 倍 → **11.9% 的资金全年躺着**。
2025-12 起投窗口：无脑 6.09%、阈值 8.13%、V2 6.76%、**P1 只有 3.74%**。

## 4. 那什么情况下"加码"才有效

| 资金性质 | 加码有效吗 | 说明 |
|---|---|---|
| **从定投预算里挪**（本方案） | ❌ 无效 | 钱只是换了个时间买，机会成本抵消收益 |
| **外部额外储备金** | ✅ **有效** | 低溢价分位（<20%）买入，历史 60 日 +7.38%，高溢价时 +2.64%，差 4.7pp |

**所以正确的做法不是"把定投的钱攒起来加码"，而是：**

1. 定投保持机械执行（5000/月，别停）
2. **另外留一笔钱**（比如 3~6 万），只在溢价分位 <20% 时打进去
3. 这笔钱平时放货币基金，年化 1.5~2%，闲置成本可以接受

---

## 5. 最终建议

| 你的情况 | 该怎么做 |
|---|---|
| 只有 5000/月，没有额外资金 | **别折腾**：用「溢价 >5% 暂停、最多等 3 月」，或直接无脑定投 |
| 有一笔额外储备（>3 万） | 定投照旧 + 储备金在溢价分位 <20% 时加仓（这才是真正有效的"加码"） |
| 溢价 >15% | 停止新增，无论哪种方案 |

**一句话**：资金的"灵活"不能创造收益，只有"买入价格更低"才能。
而溢价水平与指数高低几乎无关（相关 −0.06），所以"按溢价调度资金"本质上是在赌一个不存在的规律。

---

## 6. 数据限定

1. 只测了 159941 一只 ETF、2021-2026 与 2015-2026 两个区间。
2. 未计闲置资金的货币基金收益（若计入，各方案 +0.2~0.3pp，仍不改变排序）。
3. 未计交易成本（加码会略增交易次数）。
4. 2026 年溢价长期高位，对"分位档"这类相对阈值策略天然不利。
